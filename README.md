# Windcave Terminal for WooCommerce

Take in-person card payments on a Windcave terminal (HIT) from WooCommerce POS.

## Status

Pre-release. Not yet run against a Windcave account or terminal. Windcave QA certification is required before production use.

## Requirements

WordPress, WooCommerce, PHP 7.4+, and Windcave HIT credentials (HIT username, key, Station IDs).

## Development

```sh
composer install
composer test
composer lint
```
