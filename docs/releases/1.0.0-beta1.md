# Windcave Terminal for WooCommerce 1.0.0-beta1

First beta of 1.0.0, for the WCPOS 2.0 beta. A prerelease: install the zip by hand on a test store, against Windcave UAT. Not Windcave-certified; do not take live payments with it until Windcave QA approves production.

The extension now runs on WCPOS Pro 2.0's shared payments base and requires WCPOS Pro 2.0.0 or later. Without a compatible Pro the gateway is unavailable.

## Before you test

- Upgrade to the WCPOS 2.0 beta (plugin, Pro and app) first.
- Configure Station selection, default and lock in Pro; the extension's old defaults and locks are no longer read.
- Request UAT credentials and an agreed Vendor ID from Windcave.

## Changed

- One HIT adapter serves the app's server payment flow and Pro's order-pay panel: sale, polling, cancellation, refunds, and operator prompts answered through B1/B2 with a revision id so a late answer cannot answer a different question.
- Pro manages reader selection, the signed callback route, logging redaction and the support bundle.
- Live attempts from the previous extension are adopted into Pro's ledger on upgrade.

The full list is in `CHANGELOG.md` under 1.0.0.
