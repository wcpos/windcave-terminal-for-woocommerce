# Windcave Terminal for WooCommerce 0.1.0

**Not certified:** This integration has not yet been run against a Windcave account or a physical terminal. Windcave QA certification is required before production use.

## Added

- Cashiers can select a Windcave Station on the order-pay page, start a payment, follow terminal prompts, and see the result while the plugin polls HIT Status.
- Approved payments complete the WooCommerce order only after checking the recorded attempt, amount, environment, order total and currency. Receipts are saved to the order when returned.
- Optional FPRN notifications and a 10-minute sweep follow up payments after the cashier's page stops polling or a payment is set aside.
- A Log level setting (off, errors only or debug; debug by default while testing) writes masked diagnostics to WooCommerce → Status → Logs. Download a support bundle from the gateway settings page with the environment, masked settings, recent payment attempts without receipts and recent log lines to share with WCPOS support.
- Safeguards keep UAT and production payments separate, prevent a second Purchase before an approval is applied to the order, show Windcave errors immediately, require a terminal choice when several exist and none is the default, and require the PHP DOM extension for activation.

## If something goes wrong

Set Log level to Debug, reproduce the problem, then download the support bundle from WooCommerce → Settings → Payments → Windcave Terminal and send it with the order number to WCPOS support.

## Upgrade

First release. Configure your Windcave-issued HIT credentials and Station IDs, then enable the gateway in WooCommerce POS → Settings → Checkout. Do not use it in production until Windcave QA certification.
