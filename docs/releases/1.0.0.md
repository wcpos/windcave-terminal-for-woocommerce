# Windcave Terminal for WooCommerce 1.0.0

**Unreleased: requires WooCommerce POS Pro 2.0. Not Windcave-certified.**

This release moves HIT payments onto Pro's shared payments base. One adapter serves the app's server flow and Pro's legacy order-pay panel. Prompts on the POS order-pay panel use enabled B1/B2 buttons and a revision id; delayed answers cannot answer a different question. Native POS prompt rendering remains separate app work.

## Before upgrading

- Upgrade to compatible Pro first; without Pro 2.0 the gateway is unavailable.
- Configure Station selection/default/lock in Pro. Old extension defaults and locks are no longer read.
- Configure the default Station before refunding historical webview orders.
- Use UAT until Windcave QA approves production. Request credentials and an agreed Vendor ID from Windcave.
- Point FPRN at the generated Pro webhook URL (`wcpos/v2/payments/webhook?provider=windcave&txnRef=…`), not the old callback.

## Behavior changes / regressions

- The row amount replaces order-total charging. Pro/Free reserve pending money and reconcile after browser loss.
- Cancel needs the terminal's enabled CANCEL button and is only a request. Set-aside-and-recharge is removed.
- A replay recovers the same TxnRef through Status before any repeated Purchase.
- HIT reply currency takes precedence when present; the sent currency is only a fallback. A reported currency mismatch fails verification.
- WooCommerce matched refunds, including partial amounts and historical transaction references, are implemented. Uncertain refunds stay pending for portal verification.
- Receipts and payment history now belong to the ledger. No extension-owned receipt note, panel assets, log viewer or bundle handler remains.
- Pro supplies the support-bundle row on the gateway settings page.

## Remaining release gates

Conformance records adapter operations, not wire-message counts: replay enters create twice but sends one Purchase and recovers with Status. FPRN event IDs include the observed outcome, so identical results dedupe while a conflicting final result reaches Free's one-way transition guard. The prompt scenario has a golden transcript. No UAT, device, performance or old/new compatibility claim is made.

Release is manual only after Windcave certification.
