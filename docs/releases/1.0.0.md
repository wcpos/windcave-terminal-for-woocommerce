# Windcave Terminal for WooCommerce 1.0.0

**Requires WooCommerce POS Pro 2.0. Not yet certified by Windcave:** use Windcave UAT until Windcave QA approves production.

This is the WCPOS 2.0 version of Windcave Terminal. It runs on the payments base built into WooCommerce POS Pro 2.0, so you need WCPOS 2.0 and Pro 2.0.0 or later; without them the gateway is unavailable. Station selection, the default Station and the Station lock now live in Pro, so set them up there after you upgrade.

## Changed

- One payment flow serves the WCPOS app and the order-pay panel in Pro: payment, progress, cancel, refunds and terminal questions.
- Terminal YES/NO questions are answered with the buttons the terminal is offering. An answer that arrives late cannot answer a different question.
- Cancel works only while the terminal offers its CANCEL button, and it is a request. Otherwise cancel on the terminal.
- If a payment is retried, the plugin first asks Windcave for the result of the same transaction, before it starts a new Purchase.
- WooCommerce refunds, full and partial, go back through Windcave. A refund whose result is unclear stays pending; check it in the Windcave portal.
- Payments that were in progress when you upgrade are carried over.
- References the old plugin set aside are carried over on orders still in progress. On any other order, an order note tells staff to check the Windcave portal.
- Receipts and payment history are kept by WCPOS Pro. The plugin no longer adds its own receipt note, log viewer or support bundle.
- Removed: set aside and recharge, and the Default Station ID, Lock terminal selection, Checkout logs and Log level settings.

## If something goes wrong

Download the support bundle from WooCommerce → Settings → Payments → Windcave Terminal and send it with the order number to WCPOS support.

## Upgrade

- Upgrade WCPOS (plugin, Pro and app) to 2.0 first.
- Set Station selection, the default Station and the lock in POS settings. The old extension settings are no longer read.
- Set a default Station before you refund orders taken before this release.
- Request UAT credentials and an agreed Vendor ID from Windcave. Do not take live payments until Windcave QA approves production.
